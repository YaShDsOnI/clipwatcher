AI for hook titles, ratings and post captions

Optional. Recording, captions, speaker colours and rendering all run on this PC and never need a key. An AI only writes the hook title, the virality scores and a suggested post caption. Without one, titles come from chat for free. The AI runs in the cloud, so it uses no RAM here.

Keys are stored only on this PC, in the .env file in the data folder. A Claude Pro / ChatGPT Plus / Gemini Advanced subscription doesn't include an API key. The free API keys from Google AI Studio, Groq or OpenRouter work fine.

What's installed

Nothing is downloaded or installed unless you click it here (or answer yes in python -m clipwatcher setup). Missing optional parts just switch that feature off.

Caption model

Which Whisper model makes the captions. Smaller uses less RAM while a clip is made.

Storage

Finished clips are saved in clips, one folder per streamer, so you can copy them straight from there.
